# Loop Alarm website

This public repository contains the static website for Loop Alarm: an annotated Apple Watch app rendering with its native information-sheet interaction on the home page, the privacy policy, a minimal contact-email reveal, and site validation.

The two public routes are the home page and privacy policy. The Loop Alarm Apple Watch app source remains private and is not copied here.
