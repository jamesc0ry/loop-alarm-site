# Loop Alarm website

This public repository contains only the script-free website for Loop Alarm: an annotated Apple Watch app rendering with its information-sheet interaction on the home page, the privacy policy, and site validation.

The two public routes are the home page and privacy policy. The Loop Alarm Apple Watch app source remains private and is not copied here.
